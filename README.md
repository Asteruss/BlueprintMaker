# BlueprintMaker

Настольное CAD-приложение для параметрического проектирования деревянных окон произвольной формы — прямоугольных, трапециевидных, многоугольных, круглых и овальных. Позволяет интерактивно создавать и редактировать рамы, импосты, створки и доборы, материализовать контуры в физические доски и автоматически выводить размерные линии.

## Возможности

- **Произвольная форма рамы** — прямоугольник, трапеция (4 стороны узкого основания), правильный многоугольник, круг, овал (четырёхцентровая схема)
- **Параметрическое редактирование** — drag узлов рамы и импостов, переключение сегмента «прямая ↔ дуга» с регулировкой кривизны
- **Материализация** — контуры рамы и импостов превращаются в доски заданной ширины с автоматическим построением стыков
- **Дочерние элементы** — импосты (вертикальные, горизонтальные, несколько равноудалённых), створки, внутренние и внешние доборы
- **Соединения досок** — прямой / косой / шип, групповое изменение через макрокоманду
- **Undo / Redo** — с восстановлением параметрического поведения элементов после drag
- **Динамические размерные линии** — общие габариты и цепочки внутренних размеров с учётом дуговых сегментов
- **Дерево элементов** — двусторонняя синхронизация выделения «дерево ↔ холст»
- **Навигация** — zoom, pan, координатная сетка с авто-обновлением
- **Сохранение / загрузка** — проектный файл и автосохранение с восстановлением при аварийном закрытии

## Идея

Окно моделируется как иерархия связанных элементов: внешняя рама (замкнутый контур) содержит световые проёмы, которые делятся импостами и могут включать створки и доборы. При материализации контуры превращаются в физические доски, соединённые стыками. Каждый элемент сам пересчитывает свою геометрию при изменении входных параметров (Pull-модель), что обеспечивает консистентность состояния без ручной синхронизации.

## Стек

- **.NET 8** (multi-target: `net8.0`, `net48`)
- **Avalonia UI** — кросс-платформенный UI-фреймворк
- **ReactiveUI** — реактивные ViewModel и подписки
- **C#**

## Архитектура

Слои:

- `Domain.Models` — предметная модель (Frame, Impost, Sash, Jamb, LightSpace, Board, Joint)
- `Core.Geometry` — геометрические примитивы, контуры, `FrameShapeFactory`
- `Application` — команды, undo/redo, сервисы
- `Application.Commands` — макрокоманды и операции редактирования
- `Application.Persistence` — сохранение и загрузка проектов
- `Presentation.Avalonia` — UI, ViewModel, представление

Паттерны: Фасад, Наблюдатель, Адаптер, Состояние, Стратегия, Команда, Фабричный метод.

## Сборка

```bash
# восстановление зависимостей
dotnet restore

# запуск под net8.0
dotnet run --project Presentation.Avalonia -f net8.0

# публикация self-contained под Windows x64
dotnet publish Presentation.Avalonia -c Release -f net8.0 -r win-x64 --self-contained true -p:PublishSingleFile=true

# публикация под Linux x64
dotnet publish Presentation.Avalonia -c Release -f net8.0 -r linux-x64 --self-contained true -p:PublishSingleFile=true
```

Для сборки под `net48` требуется установленный [.NET Framework 4.8 Developer Pack](https://dotnet.microsoft.com/download/dotnet-framework/thank-you/net48-developer-pack-offline-installer).
